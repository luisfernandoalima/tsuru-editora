## 📌 Introdução

Esse projeto foi criado para ser um ERP para uma editora de livros.

- **Tema:** ERP para controle de transações, controle de estoque e gerenciamento de produtos;
- **Problema:** Em um mundo conectado, ter maior controle e transparência sob as operações de uma empresa é de alta prioridade;
- **Objetivo:** Criar um ERP (_Enterprise Resource Planning_) que possa satisfazer as necessidades de uma editora de livros.
- **Objetivos Específicos:**
  - Controle de estoque;
  - Relatórios de saídas;
  - Autenticação de usuário.

## 🛠️ Tecnologias Utilizadas

- [Nuxt.js](https://nuxt.com/) - Front-end;
- [Tauri](https://v2.tauri.app/) - Build da aplicação desktop
- [Express.js](https://expressjs.com/pt-br/) - Back-end;
- [PrismaORM](https://www.prisma.io/) - Acesso e controle no Banco de Dados;
- [PostgreSQL](https://www.postgresql.org/) - Banco de Dados.

## 🚀 Como Executar

```bash
# Clone o repositório
git clone xxx

# Acesse a pasta do projeto
cd tsuru-editora/

# instale as dependências
npm install

# execute o projeto
npm run dev

```

Acesse o front-end em: `http://localhost:3000/`

Acesse o servidor em: `http://localhost:8081/`
